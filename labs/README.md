# Laboratórios

Experimentos pequenos e isolados do domínio de pedidos, para tópicos que o sistema não cobre naturalmente. Cada pasta tem `README.md` em português, código mínimo e relatório em `docs/experimentos/`.

| Lab | Tópico |
|---|---|
| `p2p-gossip` | Peer-to-peer, descoberta de membros |
| `group-multicast` | Comunicação em grupo, ordenação FIFO/causal |
| `ipc-sockets` | Sockets TCP/UDP, serialização JSON × Protobuf |
| `clocks-election` | Lamport, vetorial, Bully/Ring, Cristian/Berkeley |
| `mini-dfs` | Sistema de arquivos distribuído |
| `compute-grid` | Grade computacional com workers |
| `mini-rpc` | Invocação remota com stub e skeleton |
